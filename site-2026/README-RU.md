# Mr. Vagus — новая заготовка персонального сайта

Ветка: codex/portfolio-sites-20261022. Существующие корневые страницы GitHub Pages сохранены.

## Смотреть

Сайт в `dist/`: `index.html`, каталог/кейсы `project.html?id=rtxc`, заметки `privacy.html`.
Статический сайт без зависимостей. Для просмотра: `python3 -m http.server 8130 --bind 127.0.0.1 --directory site-2026/dist` из корня репозитория.

## Концепция

Личная визитка + портфолио + понятные предложения сотрудничества. Английский первым; иврит после выбора структуры и текстов.
Три направления: бизнес-инструменты/автоматизация, симуляции/обучение/3D, сайты/приложения/прототипы. Игры отдельным фильтром без выдуманных релизов.
На главной человек, его подход и работы. Для заказчика — проектный бриф; для работодателя/партнёра — отдельный тип обращения. Объявление о поиске работы не включено по умолчанию.

## Наполнение владельцем

- `dist/profile.js`: имя, фото, биография, Facebook, Instagram, LinkedIn (необязательно), CV, контакт, возможность включить объявление о поиске работы. Нулевые поля — явные заготовки.
- `dist/projects.js`: единый каталог; новый проект добавляется одной записью. Указывать status, contribution, result, limit и работающую публичную ссылку. Нельзя превращать концепт в доказанный внедрённый продукт.
- Заготовка не отправляет обращения: формирует текст, копирует/скачивает. Реальный способ связи выбираем после решения владельца.

## До публичного переноса

1. Выбрать личную информацию и настоящее фото, социальные ссылки и CV.
2. Проверить формулировки услуг, статусы и собственную роль во всех кейсах; добавить подтверждённые игры/работы.
3. Сделать отдельные индексируемые страницы кейсов вместо query-based draft, метаданные предпросмотра ссылок, sitemap, языковые URL/переключение и hreflang после HE-версии.
4. Согласовать рабочие контакты, канал обращений, обработку и конфиденциальность. Не добавлять чатбот ради самого чатбота.
5. Проверить доступность, контраст, клавиатуру и реальные телефоны; производительность — сначала лабораторная, затем по реальным посетителям. Предусмотреть reduced-motion, лёгкие обложки и загрузку тяжёлых 3D только по переходу.
6. Предусмотреть сопровождение, передачу результата и ограничения в коммерческих предложениях; цены и сроки не выдумывать.
7. studio-vagus.com — окончательный адрес по указанию владельца; его DNS/текущий сайт не менялись. GitHub main не заменялся. Sites использован для workflow/дизайн-подготовки; созданный private Site не опубликован по последующему указанию владельца работать пока в GitHub.
